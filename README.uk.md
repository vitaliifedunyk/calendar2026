## 🏷️ Назва проєкту
Work Calendar 2026

## 📄 Опис
Цей репозиторій містить автогенерований код утилітарного вебзастосунку для обліку робочих годин у календарі 2026 року, розрахунку заробітку та збереження пов’язаних нотаток і цілей.

## 🧩 Призначення
Репозиторій створено як практичну утиліту для обліку робочого часу, а не як production або portfolio проєкт. Його можна використовувати для фіксації годин за днями, перегляду підсумків за місяць/рік та експорту або імпорту даних.

## 🛠 Технології
- JavaScript (ES modules)
- React
- React DOM
- Vite
- Tailwind CSS
- PostCSS + Autoprefixer
- ESLint
- Browser localStorage

## 📁 Структура проєкту
```text
.
├── src/
│   ├── components/      # UI календаря, модальне вікно запису, налаштування, пошук, керування даними
│   ├── context/         # Глобальний контекст теми/мови
│   ├── utils/           # Допоміжні утиліти для дат, перекладів, імпорту/експорту
│   ├── App.jsx          # Основна композиція застосунку та стан
│   └── main.jsx         # Точка входу застосунку
├── public/              # Статичні файли (favicon тощо)
├── dist/                # Згенерований результат збірки
├── index.html
├── package.json
└── vite.config.js
```

## 🚀 Як використовувати
```bash
npm install
npm run dev
```
Після запуску відкрийте локальну URL-адресу, яку покаже Vite (зазвичай `http://localhost:5173`).

Щоб переглянути production-збірку локально:
```bash
npm run build
npm run preview
```

## 📌 Примітки
Вихідний код у цьому репозиторії є автогенерованим. Це утилітарний згенерований код, а не вручну спроєктована production-система.
